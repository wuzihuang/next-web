NEXTBODY MCP 如何把健康数据接到 ChatGPT 与 Claude

2026年10月26日 全部说明

这篇说明只整理产品站已经写过的 MCP 内容：谁能接入、能读什么、不能当作什么用。

HOOP 是无屏智能健康手环（机身薄至 8mm、轻至 10g，不含表带）。心率、睡眠分期、训练负荷与 14 项身体扫描在 NEXTBODY App 里查看。MCP 是把该账号可选接到第三方助手的桥。

MCP 做什么

NEXTBODY MCP 不会公开所有人的数据。接入第三方 AI 助手需要你本人登录并授权，助手只能读取你自己账号下的数据。

站点目前点名的助手是 ChatGPT、Claude、Grok Bot 与 Muse。提及只为说明兼容性，不代表合作或背书；可接入的助手以 App 实际支持为准。

  • 授权后，助手可以读取你在 NEXTBODY App 里自己的身体数据。
  • 不能读取别人的账号。
  • 你没有登录并授权，MCP 就不会分享这些数据。

记录餐食默认关闭

记录餐食默认关闭。打开后可以用一句话记下这一餐；保存前助手会与你确认食物、份量和时间。热量、蛋白质、碳水与脂肪按描述估算，不是称重或实验室测定；每日目标是一般性建议，不构成营养处方。

接入的是哪些数据

MCP 读的是 App 里已经展示的健康记录。手环无屏，显示在 App。下列表述均已出现在 nextbody.ai。

  • 准备度（0–100）以昨晚睡眠为起点，对比夜间 HRV 与静息心率的个人基线。这是算法估算，仅供参考。
  • 睡眠分数满分 100，由七项因素按 HOOP 自有规则加权。不是临床量表。
  • 训练负荷（0–21）每 5 分钟结算心率区间与活动量，不能替代教练。
  • 身体扫描用生物电阻抗，再结合 App 中的身高、体重、年龄与性别，估算 14 项身体成分。结果是估算值，不是医疗诊断。植入起搏器等电子医疗设备者请勿使用。

边界、隐私与语气

数据一旦发给第三方 AI 服务，即按其隐私政策处理，接入前请自行判断。助手的分析与建议仅供参考，不构成医疗、营养或训练处方。HOOP 与 NEXTBODY App 均非医疗器械，不用于诊断、治疗、治愈或预防任何疾病。如有不适，请就医。

摘自产品常见问题

把数据接入 ChatGPT、Claude 等 AI（MCP）安全吗？

接入需要你本人登录并授权，AI 助手只能读取你自己账号下的数据。记录餐食默认关闭，开启后 AI 会在保存前与你确认食物、份量与时间。数据一旦发送给第三方 AI 服务，将按照该服务的隐私政策处理，请自行评估后使用。AI 助手给出的分析与建议仅供参考，不构成医疗、营养或训练处方。

HOOP 是医疗器械吗？

不是。HOOP 手环与 NEXTBODY App 均非医疗器械，不用于诊断、治疗、治愈或预防任何疾病。心率、血氧、HRV、皮肤温度、睡眠、身体成分、准备度、训练负荷等数据与提示仅供日常健康管理参考，不作为诊疗依据。如有身体不适，请及时就医并遵从医生建议。

饮食记录的热量和营养素准确吗？

餐食的热量、蛋白质、碳水与脂肪基于食物种类与份量描述估算，不是称重或实验室测定结果，可能与实际摄入存在差异。每日热量与营养目标为一般性建议，不构成营养处方；孕期、哺乳期、患有慢性病或有特殊饮食需求的人群请遵医嘱。
